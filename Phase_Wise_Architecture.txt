Phase 1,
# Phase 1 — Core Framework + UI + VCI Layer

Phase 1 is the **foundation of the entire platform**. Do not implement UDS, KWP2000, DTCs, DIDs, or Flashing yet.

The objective of Phase 1 is to build a **stable, scalable, cross-platform diagnostic framework** on which all future functionality will be developed.

***

At the end of Phase 1, the application should be able to:

✅ Launch on Windows/Linux/macOS

✅ Auto-scale UI

✅ Detect connected VCIs

✅ Connect/disconnect VCIs

✅ Open CAN channels

✅ Send/Receive Raw Frames

✅ Log Messages

✅ Support Plugin Loading

✅ Support Multiple VCIs

✅ Support Future Protocol Integration
